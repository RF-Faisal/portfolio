# Image assets

Upload your image files into this folder, then edit only:

`assets/js/resources.js`

Example:

```js
profile: {
  src: "assets/images/profile.jpg",
  alt: "Portrait of M Rayhan Ferdous Faisal"
}
```

## Suggested filenames

| Resource | Suggested file |
|---|---|
| Profile photo | `profile.jpg` |
| UVC-PURGE project | `project-uvc-purge.jpg` |
| Assistive robot project | `project-assistive-robot.jpg` |
| PHOENIX 3.0 rover | `project-phoenix-rover.jpg` |
| MCC Virtual Assistant | `project-mcc-assistant.jpg` |
| Universal Remote Cloner | `project-remote-cloner.jpg` |
| Best Programmer 2021 | `achievement-best-programmer.jpg` |
| Code Samurai | `achievement-code-samurai.jpg` |
| ICPC Dhaka Regional | `achievement-icpc-dhaka.jpg` |
| ICPC Asia West Final | `achievement-icpc-asia-west.jpg` |

Use landscape 16:9 images for project and achievement cards. A square portrait works best for the profile.
